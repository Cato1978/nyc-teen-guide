# 🗽 NYC Teen Guide

**La guida interattiva di New York per teenager!**

Una PWA (Progressive Web App) pensata per ragazzi e famiglie italiane in vacanza a New York City.

## ✨ Caratteristiche

- 📍 **500 luoghi** da scoprire a NYC
- 🗺️ **Mappa interattiva** con marker colorati per categoria
- 🤖 **Chatbot intelligente** con filtro budget, itinerari e suggerimenti
- ⚡ **Luoghi Harry Potter** e location di film famosi
- 🌍 **5 lingue**: Italiano, English, Español, Français, Deutsch
- 📱 **Funziona offline** - perfetta per viaggiare!
- 🔒 **Sicura per minori** - GDPR e COPPA compliant
