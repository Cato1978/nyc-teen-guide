## 🎨 Stile delle Immagini

Tutte le SVG seguono lo stesso stile:
- **Colori principali**: `#667eea` (viola), `#764ba2` (magenta)
- **Font**: Arial/Sans-serif
- **Dimensioni iPhone**: 390x844 px (iPhone 14 Pro)
- **Dimensioni Android**: 450x900 px (Pixel 7)
- **Ombre**: Drop shadow con opacità 15%
