## Come Fare gli Screenshots

### Metodo 1: Chrome DevTools (PC)
1. Apri `nyc-teen-app-secure.html` in Chrome
2. F12 → Toggle Device Toolbar (Ctrl+Shift+M)
3. Seleziona "Pixel 5" o simile
4. Cattura con Ctrl+Shift+P → "Capture screenshot"

### Metodo 2: Telefono Reale
1. Apri l'app su Android
2. Premi Power + Volume Giù
3. Screenshot salvato nella galleria

### Metodo 3: Emulatore Android Studio
1. Avvia l'emulatore Pixel 5
2. Apri l'app
3. Click sull'icona camera nella toolbar
